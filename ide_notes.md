# Сравнение VS Code и CLI при работе с Git

## 3 удобные вещи в VS Code UI
1. Наглядный просмотр изменений (diff) между версиями файла до создания коммита.
2. Удобное визуальное разрешение конфликтов слияния (Merge Conflicts) прямо в редакторе.
3. Отображение истории авторов строк (git blame) с помощью расширения GitLens.

## 1 вещь, которую удобнее делать в терминале
1. Выполнение сложных операций (интерактивный rebase, cherry-pick) и работа на удалённых серверах по SSH.

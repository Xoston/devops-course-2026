## 9. Контейнеризация

- **Способ установки Docker Engine и версия:** установлен из официального репозитория Docker. Версия: `29.9.2`.
- **Участники группы docker:** пользователь `devops`.
- **Расположение проекта на сервере:** `~/app`.
- **Расположение файла .env и его права:** `~/app/.env`, права `600`.
- **Публикуемые порты и адреса:** приложение — `127.0.0.1:5000:5000`. Порт СУБД `5432` не публикуется.
- **Именованные тома:** `app_db_data` (данные PostgreSQL).
- **Конфигурация обратного прокси-сервера:** Nginx, `location /app/` -> `proxy_pass http://127.0.0.1:5000/;`.

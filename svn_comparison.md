# Сравнение Git и SVN

## 1. Почему в Git ветвление «дешёвое», а в SVN — «дорогое»?
В Git ветка — это легкий 41-байтовый указатель на конкретный коммит в графе изменений. Создание ветки происходит мгновенно и практически не занимает места на диске. В SVN ветка создается путем полного копирования директории проекта в отдельную папку на центральном сервере, что требует времени, загрузки сети и занимает много памяти.

## 2. Можно ли в SVN сделать коммит без интернета? Почему?
Нет, в SVN сделать коммит без подключения к сети невозможно. SVN — это централизованная система контроля версий (VCS). Вся история изменений хранится исключительно на центральном сервере, поэтому любая операция фиксации (commit) требует прямого соединения с сервером. В Git же коммит делается локально на машине разработчика.

## 3. В каких сценариях SVN до сих пор может быть предпочтительнее Git?
- **Работа с очень крупными бинарными файлами (ассеты, 3D-модели, тяжелая графика):** Git копирует всю историю проекта каждому разработчику, что критично для больших файлов, а SVN хранит их централизованно.
- **Разграничение прав доступа на уровне отдельных папок:** В SVN можно дать разработчику доступ только к конкретному подкаталогу проекта, в то время как Git предоставляет доступ либо ко всему репозиторию целиком, либо закрывает его полностью.
